# Deck at /intro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the teaser deck at `/intro` on every domain and redirect the bare root there, per [issue #5](https://github.com/alau-hi/decks/issues/5) and the spec at `docs/superpowers/specs/2026-08-05-intro-url-design.md`.

**Architecture:** Declarative routing in `vercel.json` (302 redirect `/` → `/intro`, rewrite `/intro` → `/index.html`) carries the behavior on all deployments env-var-free. `middleware.js` additionally 302s `/` → `/intro` on gated deployments (middleware runs before `vercel.json` routing, so without this an unauthenticated root visit would see the gate at `/` instead of `/intro`) and moves its `?v=` viewer-identity redirect from `/` to `/intro`. `api/enter.mjs` lands signups on `/intro?v=<email>`.

**Tech Stack:** Static Vercel config, Vercel Edge middleware (`@vercel/edge`), Node serverless functions. No test framework in this repo — verification is a Node harness run against the real modules plus `curl` against deployments.

## Global Constraints

- All shell commands run from `superwood-presentation/` — `cd` in the **same** shell command (cwd does not persist between calls). **Never run `vercel` from the repo root** (it creates a public `decks` project).
- Redirects are 302/temporary (`permanent: false`) — never 308, so browsers can't cache the redirect irrevocably.
- Query strings must survive every redirect (existing `/?v=<email>` links must land on `/intro?v=<email>`).
- Do not touch the auth/HMAC logic in `middleware.js` beyond the path changes shown.
- Commit messages: short imperative descriptions (see `git log`); end with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- Deploy scripts: `npm run deploy:stage-open` (ungated staging → superwood-stage-open.vercel.app), `npm run deploy:prod` (production → sw.inventwood.net). Both are pinned to `--scope inventwood`.

- [ ] **Step 1: Write the failing harness**

Create `superwood-presentation/check-intro.mjs`:

```js
process.env.AUTH_SECRET = 'testsecret';
const { default: mw } = await import('./middleware.js');

const enc = new TextEncoder();
async function hmacHex(data, secret) {
  const key = await crypto.subtle.importKey('raw', enc.encode(secret), { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']);
  const sig = await crypto.subtle.sign('HMAC', key, enc.encode(data));
  return [...new Uint8Array(sig)].map(b => b.toString(16).padStart(2, '0')).join('');
}
const emailB64 = Buffer.from('test@example.com').toString('base64url');
const exp = Date.now() + 86400000;
const cookie = `sw_auth=${emailB64}.${exp}.${await hmacHex(`${emailB64}.${exp}`, 'testsecret')}`;

const results = [];
let r = await mw(new Request('https://sw.inventwood.net/'));
results.push(['unauth / 302s to /intro', r.status === 302 && new URL(r.headers.get('location')).pathname === '/intro']);
r = await mw(new Request('https://sw.inventwood.net/?v=test%40example.com'));
results.push(['/ redirect preserves query', r.status === 302 && r.headers.get('location').includes('v=test%40example.com')]);
r = await mw(new Request('https://sw.inventwood.net/intro', { headers: { cookie } }));
results.push(['cookied /intro gains ?v=', r.status === 302 && r.headers.get('location').includes('/intro?v=test%40example.com')]);
r = await mw(new Request('https://sw.inventwood.net/intro?v=test%40example.com', { headers: { cookie } }));
results.push(['cookied /intro?v passes through', !!(r.headers.get('x-middleware-next'))]);
r = await mw(new Request('https://sw.inventwood.net/intro'));
results.push(['unauth /intro rewrites to gate', (r.headers.get('x-middleware-rewrite') || '').includes('/gate')]);

for (const [name, ok] of results) console.log(ok ? 'PASS' : 'FAIL', name);
process.exit(results.every(([, ok]) => ok) ? 0 : 1);
```
